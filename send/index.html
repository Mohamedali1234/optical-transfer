Controls

Shrinking only applies to image files (re-encoded as JPEG, so transparency is lost) — everything else transfers untouched. Smaller images mean fewer QR frames and a faster transfer. Changes restart the stream — choose 1 lane for stability or up to 4 for max speed. Color mode packs 3 frames per code (R/G/B planes) for ~3× throughput, but needs the receiver's color mode on too, and is more sensitive to camera quality/lighting — try a larger display size and higher error correction if it struggles to lock on.

Max screen brightness helps. The stream loops forever — stop when the receiver says done.
